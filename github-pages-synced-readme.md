# SkyGlobe GitHub Pages Final (Synced with screenshots)

Upload semua file ini ke root repository GitHub Pages:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png
- splash-final.png
- app-screenshot-portrait.png
- app-screenshot-landscape.png

Langkah cepat:
1. Replace file lama di repo dengan file baru dari paket ini.
2. Pastikan GitHub Pages aktif dari branch `main` dan folder `/root`.
3. Tunggu deploy selesai.
4. Hard refresh browser.
5. Untuk audio ambience, lakukan 1 tap/klik pertama di halaman agar browser mengizinkan audio.
